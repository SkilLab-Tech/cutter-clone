## Other findings that affect the blueprint
- **Firefox 151 desktop added Web Serial (May 2026)**, per-site per-port permission; may be disabled by enterprise policy. https://hacks.mozilla.org/2026/05/web-serial-support-in-firefox/ → BP-NFR-004 should support Firefox ≥ 151, not exclude it.
- Web Serial: `flowControl` only "none"/"hardware"; `bufferSize` < 16 MB; release writer locks before close; DTR toggling can reset some USB-serial boards. Some cutters want `\n` after commands; send in small blocks (≤ 10 kB). No existing Web Serial app driving a cutting plotter was found — this project would be the first public one we know of.
- Standard HP-GL queries exist (`OH;` hard-clip limits, `OS;` status, `OI;` id, `OE;` error); one user's cutter answered `OH;` with limits in 0.025 mm units. Useful for auto-detecting width (test on the C48).
- The only open command-level mark protocol found is Graphtec/Silhouette GPGL (`TB…` + `FQ5` query), from GPL projects (inkscape-silhouette, robocut). Read for behavior only; not applicable to Foison.
- Other software: Foison sells a FoisonCut plug-in for CorelDRAW/Illustrator (R$ 430, Windows) that adds contour lines and registration marks for Camy/C lines; the E line is laser-pointer only. No third-party software is documented to drive the Foison camera. No SDK or protocol doc from Foison or SignMaster.
- SignMaster/Skycut troubleshooting that our app should encode as guidance: print at 100 % with no borderless; first mark ≥ 76 mm from the right end cap; start with the blade over the lower-right mark; camera offset calibration (lens to blade); slow down or add intermediate marks for drift; reduce nodes if the buffer overflows.
- Materials: pigment ink preferred; cure the print 24 h before laminating/cutting; never cover marks with opaque lamination; laminated media needs ~10–20 % more force (Ferax). Blades: 30° thin paper/film, 45° vinyl/paper, 60° thick (Foison blog). No published Foison force/speed numbers per material.
- Licences: vtracer MIT (npm WASM build is Node-targeted; browser build to be proven in T-013); clipper2-js and clipper2-ts BSL-1.0; Clipper2-WASM BSL-1.0.
